# 声跃 VoxLeap

> **开口，让灵感跃入文字。**

声跃 VoxLeap 是一款面向 Windows 的系统级语音输入助手：用户通过全局快捷键说话，实时查看字幕，在原文和可选的 AI 整理稿之间选择、审阅并修改，最后将文字写入当前输入框。

## 当前阶段

项目处于 **Phase 0：产品与技术验证**。

当前目录包含：

- 可交付给设计、开发和测试的 MVP 产品需求；
- 悬浮输入、实时字幕、AI 整理和审阅流程的交互规范；
- Windows 首版技术架构与风险验证方案；
- 一个无需安装依赖的浏览器交互原型。

> **最终产品不是网页。** 首版将是 Windows 托盘常驻程序：平时隐藏，用户按住自定义按键时，声纹和字幕才从屏幕底部出现。`prototype/` 只是低成本验证这种桌面交互，不会采集麦克风，也不是实际语音输入法。

## 已确定的产品原则

1. **AI 整理可关闭**：关闭后只输出转写原文，不进行生成式改写。
2. **原文永不丢失**：任何 AI 结果都可与原文对照并一键恢复。
3. **默认审阅后输入**：先让用户确认，再写入目标输入框；熟练用户可选择自动输入。
4. **字幕实时可见**：区分临时识别结果与已确认结果，并显式提示低置信内容。
5. **Windows 优先**：首版采用系统常驻应用形态，不直接实现传统 IME 内核。
6. **隐私默认收紧**：默认不保存录音、不读取周围文本、不在密码框工作。

## 查看交互原型

```bash
cd prototype
python3 -m http.server 4173
```

浏览器打开：<http://localhost:4173>

原型操作：

1. 按住键盘右侧 `Ctrl`，声纹和实时字幕从屏幕底部出现；
2. 松开 `Ctrl`，进入插入前审阅；
3. 切换“原文 / 润色 / 提纲”；
4. 修改结果并点击“写入光标处”。

也可以用鼠标按住页面右侧的演示按钮。`Esc` 可取消当前流程。右 `Ctrl` 仅是原型默认键，正式产品允许自定义。

## 第一里程碑

先完成技术风险验证，而不是立即铺开全部功能：

- 在 Cursor、VS Code、Chrome/Edge、微信、飞书、Word 中稳定写入文字；
- 在良好网络下，首条临时字幕 P95 不超过 600ms；
- 停止说话后，最终原文 P95 不超过 1.5s；
- AI 关闭时绝不调用生成式整理服务；
- 密码框、目标窗口丢失和网络中断均能安全失败且不丢原文。

达到上述门槛后，再进入 Windows MVP 正式开发。
