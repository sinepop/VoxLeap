# 运行版与 OpenLess 波形交接（2026-09-03）

> 来源：原 Obsidian 收件箱交接文档，2026-09-06 归档入项目仓库（开发过程记录归项目，不归知识库）。

## 已确认的运行版事实

- VoxLeap 个人自用版已用 Windows 自带 `csc.exe` 编译为单文件 WinForms 程序。
- 正式运行目录是 `%LOCALAPPDATA%`，保存 `VoxLeap.exe`、`settings.json` 和运行日志；`settings.json` 不同步到项目目录，避免带出 API Key。
- `VoxLeap.exe` 副本在项目目录 `声跃 VoxLeap/VoxLeap.exe`（Windows UNC：`\\wsl.localhost\Ubuntu\home\USER\ai-workspace\projects\声跃 VoxLeap\VoxLeap.exe`）。
- 对应提交：`509b47b feat(voxleap): ship personal Windows runtime and glass wave UI`。

## 本轮 UI 决策

- 录音浮层用逐像素 alpha 的浅色"声纹玻璃"，尺寸收敛 `420×88`。
- 参考 OpenLess 紧凑胶囊与圆角音频短柱（github.com/Open-Less/openless `Capsule.tsx`），加入 5 根随真实麦克风 RMS 电平起伏的短柱；不用固定循环假动画。
- MCI 仍负责生成 WAV；并行 WinMM `waveIn` 只算电平，不接管录音文件。
- 移除录音态右侧 `Ctrl / 松开完成` 小卡；识别处理中不显示第二个状态小方块。
- 完成提示为按文字宽度自适应短胶囊，成功文案"已输入 N 字"。

## 验证与边界

- Windows 实际编译、重启、右 Ctrl 按键级检查通过：浮层可见、窗口 `420×88`、无激活样式；释放后进程响应，录音/识别无报错。
- 独立探针确认 `waveIn` 持续收到 PCM 缓冲且可与 MCI 同时打开；ASR 评测单元测试 44 项通过。
- 当前是可直接运行的单文件 exe，非安装包；正式运行实例从 C 盘目录启动。
