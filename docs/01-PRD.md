# 声跃 VoxLeap MVP 产品需求文档

- 版本：0.1
- 状态：产品基线，待 Phase 0 技术验证
- 首发平台：Windows 10/11
- 产品口号：开口，让灵感跃入文字

## 1. 产品定义

声跃 VoxLeap 是一款系统级语音输入助手。用户在任意受支持的输入框中唤起声跃，说话时查看流式字幕，结束后选择原文或 AI 整理稿，审阅、编辑并写入原输入位置。

### 1.1 核心价值

- 比键盘更快地捕获完整思路，减少灵感在组织和敲字过程中丢失。
- 用实时字幕和输入前审阅建立“我知道系统听到了什么”的信任感。
- 将 AI 作为可选整理层，而不是不可绕过的黑箱。
- 对中英文混说、技术名词和 Vibe Coding 场景提供针对性体验。

### 1.2 术语约定

- **转写原文**：ASR 根据语音生成的最终文本，可包含基础标点恢复。
- **AI 整理**：由生成式模型进行去口头语、语句修复或结构重组。
- **关闭 AI**：只关闭生成式整理，不代表关闭语音识别。
- **临时字幕**：仍可能被 ASR 修订的流式结果。
- **确认字幕**：ASR 已标记为稳定的片段。
- **目标输入框**：用户唤起声跃时原本聚焦的可编辑控件。

## 2. 目标用户与首要场景

### 2.1 核心用户

1. **Vibe Coding 用户**：在 Cursor、VS Code 或浏览器中快速描述需求、补充约束和反馈结果。
2. **高频沟通者**：在微信、飞书、邮件中输入较长内容。
3. **写作者与知识工作者**：在 Word、Notion、在线文档中捕捉段落和提纲。
4. **打字不便用户**：需要更低操作负担的文本输入方式。

### 2.2 首版关键任务

- 用户可以在当前应用内用一个全局动作开始说话。
- 用户在说话期间能及时发现明显识别错误。
- 用户停止后可以直接使用原文，完全绕过生成式 AI。
- 用户可以切换 AI 整理方式并看见结果差异。
- 用户修改后能可靠地把文本放回原输入位置。

## 3. 产品原则

1. **原文优先**：原文是唯一事实来源，AI 结果是派生版本。
2. **控制权可见**：不能使用含义模糊的单一“AI 开关”；使用“原文 / 轻整理 / 结构化”明确表达结果类型。
3. **默认可审阅**：MVP 默认不自动发送、不代替用户按下聊天软件的发送键。
4. **先可靠后炫酷**：动画不能延迟字幕、抢夺焦点或遮挡工作内容。
5. **安全失败**：目标丢失、权限不足、网络断开时保留草稿，不向未知窗口注入。
6. **隐私最小化**：不默认保存录音、正文或上下文。

## 4. 端到端用户流程

1. 用户将光标放在目标输入框。
2. 用户按住自定义全局快捷键，声跃记录目标应用和控件。
3. 无激活悬浮胶囊出现，100ms 内给出监听反馈。
4. 用户说话，胶囊展示音量、临时字幕和确认字幕。
5. 用户松开快捷键，系统停止录音并等待 ASR 最终结果。
6. 审阅卡片出现，默认展示用户预设的结果模式；原文始终可切回。
7. 用户可修改、重录、复制、取消或插入。
8. 系统重新确认目标，恢复焦点并注入文字。
9. 显示短暂完成提示；不自动发送内容。

## 5. MVP 功能需求

### 5.1 唤起与目标捕获

- **VX-ACT-01**：支持用户自定义全局快捷键，必须检测与系统快捷键冲突。
- **VX-ACT-02**：支持“按住说话、松开结束”和“按一次开始、再按一次结束”。
- **VX-ACT-03**：唤起时记录目标窗口、进程和可编辑控件特征。
- **VX-ACT-04**：监听悬浮层不得抢走目标输入框焦点。
- **VX-ACT-05**：在密码框、锁屏、安全桌面和明确不支持的控件中拒绝启动，并说明原因。

### 5.2 录音与流式字幕

- **VX-REC-01**：显示当前麦克风和实时音量反馈。
- **VX-REC-02**：支持麦克风切换、静音和权限错误引导。
- **VX-REC-03**：字幕区最多显示三行，内容增多时聚焦最新片段。
- **VX-REC-04**：临时字幕与确认字幕具有不同视觉状态。
- **VX-REC-05**：当引擎提供置信度时，低置信词以非颜色唯一依赖的方式提示。
- **VX-REC-06**：用户可在等待最终结果期间取消；取消后不得调用 AI 整理。

### 5.3 原文与 AI 整理

结果选择采用三段式控件：

1. **原文**：不调用生成式模型。
2. **轻整理**：去除口头语、恢复明显标点和断句，不重排主要信息。
3. **结构化**：在不改变事实的前提下整理段落、列表和表达顺序。

- **VX-AI-01**：AI 整理只能以 `originalTranscript` 为输入来源之一，不能覆盖该字段。
- **VX-AI-02**：用户选择“原文”时，客户端不得向生成式整理服务发起请求。
- **VX-AI-03**：切换到 AI 模式时异步请求，原文仍可立即使用。
- **VX-AI-04**：结果必须保留数字、否定关系、代码标识符、文件路径、URL 和专有名词；无法保证时给出警告。
- **VX-AI-05**：支持原文与整理稿差异展示，至少能标示新增、删除和替换。
- **VX-AI-06**：AI 失败或超时不得阻止用户编辑和插入原文。
- **VX-AI-07**：Vibe Coding 预设属于“结构化”的专用模板，MVP 可隐藏在实验功能中。

### 5.4 审阅与编辑

- **VX-REV-01**：审阅卡片支持编辑、撤销、全选和常用文本快捷键。
- **VX-REV-02**：切换结果模式前保存用户草稿，避免无提示覆盖编辑内容。
- **VX-REV-03**：提供“插入”“复制”“重录”“取消”四个明确动作。
- **VX-REV-04**：默认不自动发送消息、不执行代码、不触发目标应用提交动作。
- **VX-REV-05**：用户关闭审阅卡片时，若已有内容必须支持恢复或确认丢弃。

### 5.5 写入目标应用

- **VX-INS-01**：插入前验证目标窗口仍存在，且不是密码或敏感输入控件。
- **VX-INS-02**：目标变化时暂停注入，并让用户重新选择目标或复制文本。
- **VX-INS-03**：支持中文、英文、Emoji、标点和多行文本。
- **VX-INS-04**：长文本注入失败时保留审阅草稿并提供复制，不得静默丢失。
- **VX-INS-05**：剪贴板回退不得永久覆盖用户原剪贴板；检测到剪贴板已被其他程序更新时不强行恢复。
- **VX-INS-06**：提供一次“撤销本次插入”的能力；无法可靠撤销时明确提示使用目标应用撤销。

### 5.6 设置与托盘

- **VX-SET-01**：设置默认快捷键、交互方式、麦克风、语言和默认结果模式。
- **VX-SET-02**：设置开机启动、动画强度和自动输入；自动输入默认关闭。
- **VX-SET-03**：展示服务连接状态、剩余用量和隐私策略入口。
- **VX-SET-04**：历史记录默认关闭；开启时说明保存位置、期限和删除方式。
- **VX-SET-05**：托盘菜单支持开始输入、打开设置、暂停服务和退出。

## 6. 异常与恢复

| 场景 | 必须行为 |
|---|---|
| 无麦克风权限 | 不开始录音；显示系统设置入口 |
| ASR 网络中断 | 保留已确认字幕；允许重试或复制 |
| 一直没有检测到人声 | 给予提示，不生成空记录 |
| AI 超时 | 立即回退到原文，不阻塞插入 |
| 用户切换了应用 | 暂停注入，要求确认新目标 |
| 目标应用以管理员运行 | 不自动提权；说明限制并提供复制 |
| 内容过长 | 分段处理或提示限制，原文不可丢失 |
| 应用意外退出 | 若用户开启草稿恢复，则本地加密保存；否则不保留正文 |

## 7. 非功能目标

以下是产品目标，不是当前已验证结果：

- 快捷键触发至监听反馈：P95 ≤ 150ms。
- 良好网络下首条临时字幕：P95 ≤ 600ms。
- 停止录音至最终原文：P95 ≤ 1.5s。
- 300 个汉字以内 AI 整理：P95 ≤ 3s，超时可立即回到原文。
- 首批目标应用文字注入成功率：≥ 99%。
- 崩溃无感会话比例：≥ 99.5%。
- 空闲内存、CPU 和安装包体积需在技术验证后设定预算。
- 动画目标 60 FPS，并支持系统“减少动态效果”。

## 8. 隐私与安全

- 默认不落盘保存音频。
- 默认不保存完整转写和整理稿到日志、遥测或崩溃报告。
- 网络传输使用 TLS；供应商、数据区域和保留政策对用户可见。
- API 凭据使用 Windows 安全存储，不以明文配置文件保存。
- 上下文感知、历史记录、云同步均为独立的明确授权。
- 统计默认只包含延迟、错误码、内容长度区间等非正文数据；提供关闭入口。

## 9. MVP 范围外

- 注册为传统 Windows TSF 输入法。
- macOS、Linux 和移动端客户端。
- 自动读取项目仓库或输入框周围内容。
- 自动发送聊天消息或自动执行代码。
- 实时多人协作、团队术语库和云同步。
- 完整离线 ASR 与私有化部署。
- 通过语音执行删除文件、运行命令等高风险动作。

## 10. 首批兼容性矩阵

必须真实测试以下应用，不以浏览器原型结果代替：

- Cursor
- Visual Studio Code
- Chrome 与 Edge 普通网页输入框
- 微信 Windows 客户端
- 飞书 Windows 客户端
- Microsoft Word

第二批：Notion、Outlook、企业微信、JetBrains IDE、Windows Terminal、远程桌面。

## 11. MVP 验收场景

1. 用户在 Cursor 输入框按住快捷键，说出包含中英文技术名词的一段话，实时看到字幕，选择原文并成功插入。
2. 用户选择轻整理，查看与原文差异，修改一个词后插入微信，但系统不自动发送。
3. AI 服务断开时，用户仍能立即查看、编辑和插入原文。
4. 用户录制期间切换窗口，系统不会把内容静默注入新窗口。
5. 用户在密码框触发快捷键，系统拒绝录音且不泄露输入框信息。
6. 长文本使用剪贴板回退后，用户原剪贴板在安全条件下恢复。
7. 用户按 `Esc` 取消，录音缓存被释放，且不产生 AI 请求。

## 12. 产品成效指标

- 新用户首次成功输入完成率。
- 每周活跃用户的有效语音输入次数。
- 原文直接采用率、AI 整理采用率和整理后再编辑率。
- 字幕出现延迟、最终结果延迟、注入失败率。
- 用户主动取消率和重录率。
- AI 结果恢复原文的比例；该指标异常升高说明整理质量或信任机制存在问题。
